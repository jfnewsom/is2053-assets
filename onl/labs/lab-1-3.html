Who Reached the Beach?
← Back: CP1

Lab 1.3 adds a second beach, Galveston. Before anyone can get there, your ending has to know that Galveston counts as a beach. You'll rewrite the ending with or and a Boolean variable called reached_beach. Nothing the player sees changes in this checkpoint: every run prints exactly what it printed in CP1.

Why This Matters

or lets one if check two things: the condition is true when either side is true. A Boolean variable holds True or False, a yes-or-no answer your program can check later. Changing how code works without changing what it prints is called refactoring, and running the same tests before and after is how you know nothing broke.

"When I first learned the or operator, I kept writing if current_city == 'Corpus Christi' or 'Galveston': and wondering why every single trip got the beach banner. You need the full comparison on both sides of the or. Trust me, this trips everyone up at first!"
Tyler Nguyen
Junior Developer, Bat City Collective
Step-by-Step Instructions
  1. Replace your whole # Where did you end up? block, from the comment down through the print() under the Austin line, with this. Three lines change: status = 'Trip Incomplete' becomes reached_beach = False, the first if checks two cities with or, and status = 'BEACH WINNER!' becomes reached_beach = True.
    # Where did you end up?
    reached_beach = False
    if current_city == 'Corpus Christi' or current_city == 'Galveston':
        print('=' * 50)
        print('CONGRATULATIONS! YOU REACHED THE BEACH!')
        print('=' * 50)
        print()
        reached_beach = True
    elif current_city == 'Austin':
        print('Austin is fun, but no beach here!')
        print()
  1. Leave one empty line, then set the status from reached_beach. This block goes above the # Final trip report comment, with one empty line between them:
    # Decide the status
    if reached_beach:
        status = 'BEACH WINNER!'
    else:
        status = 'Trip Incomplete'
True and False are not strings

Write True and False with a capital letter and no quotes. false is a NameError. 'False' in quotes is a string, and any string that isn't empty counts as true in an if, so every player would be a beach winner.

Keep Going?
← Back: CP2

When the player makes it to Houston, the beach is only 50 more miles away. Your program asks whether they want to keep going. A y or Y sends them toward Galveston; any other answer, and they stay in Houston.

Why This Matters

This question only makes sense once you're in Houston, so it's an if inside another if: the outer one checks where you are, and the inner one checks what the player typed. Python compares text exactly, so 'y' and 'Y' are different strings. or lets one check accept both.

Step-by-Step Instructions
  1. Find the end of your travel block: the print() at four spaces, right after the You will need to roll again next time! line. Leave one empty line below it. Then, above # Where did you end up?, add this block, with one empty line after it:
    # Keep going to Galveston?
    if current_city == 'Houston':
        answer = input('Continue to Galveston? (y/n): ')
        print()
        if answer == 'y' or answer == 'Y':
            destination = 'Galveston'
            distance = HOU_TO_GALVESTON
            print(f"You're headed to {destination}!")
            print(f'Distance: {distance} miles')
            print()
            print()
  1. Check the indentation. The question is at eight spaces, inside if current_city == 'Houston':. The Galveston lines are at twelve, inside the y check. The two print() lines at the end are on purpose: CP4 puts the last 50 miles between them.
The or trap, again

if answer == 'y' or 'Y': runs for every answer, even n, because 'Y' on its own counts as true. Each side of the or needs its own answer ==.
