Key Concepts

A class is a blueprint; an object (an instance) is one thing built from it. City('Houston', 'GATEWAY', 'Space City') runs the class's __init__ method, which stores those values in the new object's attributes. An attribute whose name starts with two underscores, like self.__name, is private: code outside the class can't reach it, so it asks through methods. An accessor returns an attribute's value; a mutator changes it. Every method's first parameter is self, the object the method was called on: in houston.get_tagline(), self is houston. __str__ returns the text Python uses when you print an object or put it in an f-string. A refactor changes how code is organized without changing what it does.

What You're Building

Why This Matters

Right now one city's data is split across two dictionaries: its roads are in distances, and its type and tagline are in city_info. A City object holds all of it in one place. Tips & Pitfalls
One underscore, or none self.name and self.__name are different attributes. Use two underscores everywhere, or a method reads an attribute that was never set and you get an AttributeError.
Forgetting self Every method's first parameter is self. Without it, calling houston.get_tagline() raises a TypeError.
build_cities inside main() Define it at the top level of the file, like trivia_gate, and only call it from main().
ModuleNotFoundError: No module named 'city' The file must be named exactly city.py and sit in the same folder as lab-5-1.py. Open the folder in VS Code, not the file.

One course rule on top of that: to show a number to a set number of decimal places, format it in an f-string, like f'{rate:.1f}', instead of using round(). Here's why: round() changes the number itself, while an f-string changes only what's shown, so the full value is still there for the math that comes later. Picture plotting a course from El Paso to San Antonio: about 500 miles on a steady heading of 108.77 degrees. Round the heading to 109 and you're off by less than a quarter of a degree, which sounds like nothing. Fly it anyway and you miss San Antonio by about 2 miles. Round on every leg of a longer trip and the misses can stack up. Keep the full number for the math, and display only what you print.
