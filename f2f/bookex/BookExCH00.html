Setup Check
Chapter 0  •  2 Programs

BookEx 0 is your setup check, and it has exactly one job: prove that everything works before the real assignments begin. Two very short programs. The first confirms your Python, VS Code, and CodeGrade pipeline is connected end to end. The second confirms you have your textbook and can work from it, because every BookEx after this one is typed straight from the book. Finish both by Sunday and Week 2 will hold no surprises.

Learning Objectives
  • Confirm Python and VS Code are installed and working
  • Submit a program to CodeGrade and see it pass
  • Type a short program from the textbook and match its output exactly
  • Create and assign a variable
Key Concepts

BookEx 0 previews two ideas from Chapter 2: displaying output with print() and storing a value in a variable. Chapter 2 proper begins next week in BookEx CH02.

Textbook Reference

Starting Out with Python, 6th Edition by Tony Gaddis, Chapter 2: Input, Processing, and Output (Program 2-4)

Program Requirements
  • Each program is saved as its own individual .py file
  • Each file uses the exact filename listed in the instructions
  • Each program runs without syntax errors
  • Output matches exactly. CodeGrade compares character by character

What You'Re Building

A one-line program that proves your entire toolchain works: Python runs it, VS Code edits it, and CodeGrade grades it. If you completed Start Here, you have already written this file. This checkpoint is where it gets submitted for credit.

The Code

Step-By-Step Instructions
  1. If you have not completed the Start Here walkthrough, do that first. It builds this exact file with you.
  2. Confirm your file is named hello.py and contains the single line shown in the code block above.
  3. Run it and confirm the output reads: Hello, World!
  4. Capital H, capital W, comma, space, exclamation point. CodeGrade compares character by character.
Copy the Spec, Don't Retype It

When the instructions show you the exact code or text a program should use, copy and paste it. Zero typos, zero case mistakes. Professionals do this constantly. Save your typing energy for the parts that require thinking.

What You'Re Building

A four-line program from your textbook that creates a variable, then displays a message and the variable's value. This is your first taste of the pattern every BookEx uses: open the book, type the program exactly as shown, run it, and match the output. Step-By-Step Instructions
  1. Open your textbook to Program 2-4.
  2. Create a new file named variable_demo.py.
  3. Type the program exactly as shown in the book.
  4. Run the file and confirm the two output lines match the book.
  5. Fix any typos until it runs cleanly.
