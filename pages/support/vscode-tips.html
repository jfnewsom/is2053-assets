Keep your hands on the keyboard
Autocomplete: Pick It, Don’t Type It

As you type, VS Code shows a list of names that match what you have so far: your own variables, Python’s built-ins like print and input, and, once you import a module, its functions. You never have to take your hands off the keyboard.

WhatWindowsMac
Move through the listUp DownUp Down
Pick the highlighted nameEnter or TabEnter or Tab
Close the listEscEsc
Open the list againCtrl+SpaceControl+Space

Why it matters: a name you pick from the list can’t be misspelled, and a misspelled name is the most common cause of a NameError.

In Lab 2.2: type function_library. (with the dot) and the list shows every function in your library, spelled the way you wrote it.

This list is not AI. It only offers names that already exist. Gray text that appears inline as you type is AI, and you turned that off in Start Here.

First used in Lab 1.1, Checkpoint 2.

When your program crashes, the last File ... line entry in the error message names the file and the line. Go straight there instead of scrolling.

Click anywhere on a line (or select several lines) and toggle a # at the start of each one. Press it again to take the # back off.

Move a Whole Block In or Out

Every time a lab wraps your existing code in a new loop, every line of that code moves in one level. You don’t have to re-type the spaces.

WhatWindowsMac
Indent the selected linesTabTab
Outdent the selected linesShift+TabShift+Tab
Indent the current line, nothing selectedCtrl+]Cmd+]
Outdent the current line, nothing selectedCtrl+[Cmd+[

Wrapping code in a new loop:

  1. Type the new loop above the old code, at the old code’s indent (for example playing = True, then while playing:).
  2. Select every line that goes inside the loop, from the first through the last.
  3. Press Tab once. The whole block moves in one level.
  4. Check the thin vertical lines VS Code draws at each indent level: the old block should sit one line to the right of the new while.
  5. Run it before you add anything else.

Spaces, not tabs: the course folders make Tab insert 4 spaces. The status bar at the bottom of VS Code should say Spaces: 4. If it says Tab Size, click it and choose Indent Using Spaces, then 4. Mixing tabs and spaces gives a TabError.

First used in Lab 2.1, Checkpoint 4.

Collapse a Block to See the Shape

When loops sit inside loops, collapse the ones you aren’t working on. A collapsed block shrinks to its first line, so you can see how the blocks around it fit together.

Hover over the line numbers: a small arrow appears next to every line that starts a block (def, while, if). Click it to collapse or expand that block. Shift+click collapses everything inside it too.

WhatWindowsMac
Collapse the block you’re inCtrl+Shift+[Option+Cmd+[
Expand itCtrl+Shift+]Option+Cmd+]
Collapse everythingCtrl+K then Ctrl+0Cmd+K then Cmd+0
Expand everythingCtrl+K then Ctrl+JCmd+K then Cmd+J

Collapsing only changes what you see. The code is all still there, and it all still runs.

First used in Lab 2.3, Checkpoint 3.

Sticky Scroll: See Which Loop You’re In

As you scroll down through nested code, Sticky Scroll pins the first line of each block you’re inside (def main():, then each while) to the top of the editor, so you always know which loop a line belongs to. Click a pinned line to jump to it.

The course folders turn it on. Anywhere else, open Settings (Ctrl+,, Mac Cmd+,), search Sticky Scroll, and check Editor › Sticky Scroll: Enabled.

First used in Lab 3.1, Checkpoint 3.

Find Every Line That Uses a Name

Before you delete a constant, a list, or a function, check that nothing still uses it. Click the name and press the keys: VS Code lists every line that uses it, in every open file, and you can click one to jump there. When the only line left is the one that defines it, it’s safe to delete.

WhatWindowsMac
Show every useShift+F12Shift+F12 (on some laptops fn+Shift+F12)
Close the listEscEsc

First used in Lab 4.1, Checkpoint 4.

Find and Replace

When the same text has to change in several places, let VS Code find every copy. Type what to find in the top box and what to put in its place in the bottom one. The box shows how many it found, like 1 of 3, so you know before you change anything. Replace them one at a time, or all at once.

WhatWindowsMac
Open Find and ReplaceCtrl+HCmd+Option+F
Replace this one, go to the nextCtrl+Shift+1Cmd+Shift+1
Replace allCtrl+Alt+EnterCmd+Enter

Type the whole text you mean, not just part of it, so nothing else matches by accident.

First used in Lab 4.2, Checkpoint 4.
