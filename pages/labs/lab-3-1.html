The Main Menu
← Back: CP1

A main menu, the first thing a player sees: start a new game, load a saved one, or quit. After a session ends, the menu comes back.

Why This Matters

The menu is one more loop, while in_program:, around everything after the banner. Choose 3 and the loop's flag turns False; continue jumps back to the top, where the loop sees the flag and stops. New Game asks for a name and starts the session totals. Load can't load anything yet, so for now it says there's no save file and starts a new game, which is exactly what it will do in CP5 when there isn't one. Load is checked before New Game, so that fallback can run New Game next.

"Count the loops: in_program, play_again, playing, and the travel loop. Four, and each has one job. The menu picks what to do. play_again runs one game after another. playing runs one leg after another. The travel loop runs one turn after another. If you're not sure where a line goes, ask which of those jobs it's part of."
Danny Cavanaugh
Lead Developer, Bat City Collective

Checkpoint

The OPTIONS Menu
← Back: CP2

A three-way choice in place of Keep going this trip? (y/n): . Each time you arrive in Houston or San Antonio, you can continue the journey, save and quit, or quit without saving. Save and quit comes alive in CP4; this checkpoint wires up the other two.

Why This Matters

A yes or no question can't hold three answers, so it becomes a menu, validated by get_valid_int() like every other menu. Quitting without saving still ends the game with a report, and the report should say why it ended. A Boolean flag, quit_without_saving, carries that from inside the loop to the status line after it. Every game starts it at False, so it can't leak from one game into the next.

"Players hate guessing what a menu choice did. When I quit a trip, the report should say I quit, not Trip Incomplete like something went wrong. One flag set where it happens, one line in the status check. That's the whole fix."
Tyler Nguyen
Junior Developer, Bat City Collective

def load_game():
    """
    Load the game from SAVE_FILE.

    Returns:
        tuple: The nine saved values, in the order save_game() writes

        total_miles = int(infile.readline().rstrip('\n'))
        total_turns = int(infile.readline().rstrip('\n'))

        infile.close()
        return (player_name, current_city, total_miles, total_turns,
