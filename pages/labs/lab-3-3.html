Hazards as Parallel Lists
← Back: CP1

Six hazards instead of three, kept in three parallel lists: the hazards, what happens on HEADS, and what happens on TAILS. One library function picks one, and the long if/elif chain in the hazard block goes away.

Why This Matters

Same idea as CP2 in Lab 3.2, with three lists instead of two: position 3 in all three lists describes the same hazard. get_random_hazard() picks one random position and returns all three values at once. Adding a hazard is now three lines of data, not another elif branch. Three hazards are new, with new text; the three from Lab 2.2 keep theirs.

"Back in Lab 2.2 I said hardcoded hazards wouldn't scale. Every new one meant another elif and three more lines of if-chain. Lists fix that: the code that picks a hazard never changes again, no matter how many you add."

def get_random_hazard(names, heads_msgs, tails_msgs):
    """
    Pick a random hazard from three parallel lists.

    Args:
        names (list): The hazards
        heads_msgs (list): What happens on HEADS, in the same order
        tails_msgs (list): What happens on TAILS, in the same order

    Returns:
        tuple: A hazard and its HEADS and TAILS messages
    """
    index = random.randint(0, len(names) - 1)
    return names[index], heads_msgs[index], tails_msgs[index]

Unique Cities and Escape Rate
← Back: CP2

Two new numbers in the report: how many different cities you visited, and what percent of your hazards you escaped.

Why This Matters

A trip home from Austin puts San Antonio on the route twice. To count each city once, build a second list: go through the route, and append() a city only when it's not in the new list yet. The escape rate divides escapes by hazards, so it only makes sense when there was at least one hazard; dividing by zero stops the program. f'{escape_rate:.1f}' turns the number into a string with one digit after the decimal point.

"Raw totals are fine. A percentage is a score. Players will replay a trip just to push their escape rate up, and 'four cities' sounds like a road trip in a way that 'five stops' doesn't."
Sasha Mireles
Creative Director, Bat City Collective
Step-by-Step Instructions
  1. Right after the status is decided (after status = 'Trip Incomplete' and the empty line under it), build the list:
            # Each city once, in the order you first reached it
            unique_cities = []
            for city in visited_cities:
                if city not in unique_cities:
                    unique_cities.append(city)
  1. In the report, right after the YOUR ROUTE call, print the count and an empty line:

  1. In STATISTICS, under the Hazards Escaped line, add the rate, only when there were hazards:

← Back: CP3

A trip report that outlives the game. After every finished game, the report goes into trip_report.txt, in its own plain layout: the route on one line with arrows, the statistics, and the hazards A to Z.

Why This Matters

Lab 3.1 wrote a file for the program to read back; this one is for people to read. The function opens the file in 'w' mode, so each game's report replaces the last one. Its layout is simpler than the screen's, so it builds the route as one line: start with an empty string and add each city, with ' -> ' before every city but the first. The hazards need to be sorted before the screen report now, because the file uses them too.

Terrence "T-Bone" Booker

                     total_turns, total_hazards, total_escaped,

                     status):
    """
    Write the trip report to a file.

    Args:
        filename (str): The file to write
        player_name (str): The player's name
        current_city (str): Where the game ended
        total_miles (int): Miles this game
        total_turns (int): Turns this game
        total_hazards (int): Hazards faced this game
        total_escaped (int): Hazards escaped this game
        visited_cities (list): Every city this game, in order
        unique_cities (list): Each city once
        sorted_hazards (list): The hazards, A to Z
        status (str): How the game ended
    """

    outfile.write('\n')

    outfile.write(f'  Hazards Escaped: {total_escaped}\n')

        rate = (total_escaped / total_hazards) * 100
        rate_str = f'{rate:.1f}'
        outfile.write(f'  Escape Rate: {rate_str}%\n')
    outfile.write('\n')

    if len(sorted_hazards) > 0:

    outfile.write('\n')

    outfile.write('=' * 40 + '\n')
    outfile.close()
