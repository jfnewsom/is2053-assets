The file every lab in this course starts from: a header at the top, the named constants, the main() structure, and the game's banner. At the end of this checkpoint your program runs and prints the banner.

Why This Matters

CodeGrade reads your header for your name, ID, and section, and it scores the header and your docstrings on every lab. Those points are free once the format is right, so get it right once here and copy it forward. Named constants keep the game's numbers in one place: if a distance changes, you change one line.

Where every line you add goes

def main(): gives your program a name, and the main() line at the bottom runs it. From here on, every line you add goes inside main(): indented four spaces, below the banner, and above the two empty lines before if __name__.

  • Type def main(): only once. A second one causes the "redefinition of unused 'main'" style error.
  • The if __name__ == '__main__': line stays at the very bottom, at the left margin, with main() indented under it.
  • Each block of code starts with a # comment line saying what it does, with one empty line above it. The one exception is the first block in a function, which sits right under the docstring. Type the comments shown in the steps: CodeGrade's Documentation check looks for at least three by the time you submit. CP1 gives you two, and CP2 adds the third.
  • Empty lines must be truly empty. A space or tab on an empty line is a style error.

The dice roll. The player types a number from 1 to 20, the game turns it into miles, and it shows where you can go from San Antonio.

Why This Matters

Everything input() hands back is text, even when the player types a number. int() turns that text into a whole number you can do math with. This pattern, input then convert then use, is the most common shape in Python programs. You'll write it constantly in this course.

Step-by-Step Instructions
  1. Leave one empty line after the goal block. Then ask for the roll, turn it into a whole number, and store it in roll. Then add the blank line:

  1. Show the roll and the miles, then a blank line:

    print(f'You travel {miles_rolled} miles...')

Travel Report
← Back: CP3

The math: how many miles are left to each destination after your roll, including Galveston, which you reach through Houston. Then the Travel Report that shows it all.

Why This Matters

Each calculation gets its own line and its own variable, so you can check each one by itself. Galveston takes two steps: first the total distance, then what's left after your roll. And one run can't prove your math: a mistake can look right on one roll and wrong on another. That's why you'll test three rolls.

Step-by-Step Instructions
  1. Leave one empty line after the destination list, then calculate the miles left to each destination. Every line is distance first, then minus miles_rolled:
    # Miles left to each destination
    corpus_remaining = SAT_TO_CORPUS - miles_rolled
    houston_remaining = SAT_TO_HOUSTON - miles_rolled
    austin_remaining = SAT_TO_AUSTIN - miles_rolled
    galveston_total = SAT_TO_HOUSTON + HOU_TO_GALVESTON
    galveston_remaining = galveston_total - miles_rolled

VS Code underlines these new names as unused for now. The underlines go away in the next step, when the report prints them.

  1. Leave one empty line, then print the Travel Report:
    # Travel report
    print('=' * 50)
    print('TRAVEL REPORT')
    print('=' * 50)
    print(f'Driver: {player_name}')
    print('Miles remaining after your roll:')
    print(f'  Corpus Christi: {corpus_remaining}')
    print(f'  Houston: {houston_remaining}')
    print(f'  Austin: {austin_remaining}')
    print(f'  Galveston (via Houston): {galveston_remaining}')
    print()
    print('Zero or less = you made it!')
    print('More than zero = you still have miles to go.')
    print()

If Something Breaks

Common failure patterns and where they came from:

Symptom Where to Look
Nothing prints, and there's no error Check CP1 (Setup & Banner): the if __name__ == '__main__': line must be at the bottom, at the left margin, with main() indented under it.
SyntaxError on line 1 Check CP1 (Setup & Banner): the header's closing """ is missing.
NameError: name 'SAT_TO_HOUSTON' is not defined (or any other constant) Check CP1 (Setup & Banner): a constant is missing or misspelled. All five must be defined at the top of the file.
You travel 15151515151515151515 miles... Check CP3 (The Roll): int() is missing around input().
Output shows {player_name} or {roll} instead of a value Check the line that prints it: the f before the opening quote is missing.
A report number has the wrong sign (50 instead of -50, or the other way around) Check CP4 (Travel Report): that subtraction is backwards. Distance first, then minus miles_rolled. Run rolls 1 and 20 too; roll 15 can hide it.
