A new file, city.py, holding a City class: a constructor that stores four private attributes, a getter and a setter for the name, the type, and the tagline, and add_connection() for the roads. A self-test at the bottom checks every one. Then build_cities() in lab-5-1.py turns your two dictionaries into one City object per city, and every stop asks its City for the tagline.

Why This Matters

Right now one city's data is split across two dictionaries: its roads are in distances, and its type and tagline are in city_info. A City object holds all of it in one place. Its attributes are private, so code outside the class can't reach them directly; it asks through methods instead. A getter (Gaddis calls it an accessor) returns one attribute; a setter (a mutator) changes one. That's encapsulation, the main idea of Chapter 10.

"Two files, two jobs. city.py describes what a city is. lab-5-1.py runs the game. Notice that city.py never opens a data file: the game loads the files the way it always has, then hands each city's data to the class. The class doesn't care where the data came from."

class City:
    """
    One city in the road trip game.

    Private attributes:
        __name (str): The city's name, like 'San Antonio'
        __city_type (str): Its type from city_info.txt, like 'WIN'
        __tagline (str): Its tagline from city_info.txt
        __connections (dict): Each road: destination name -> miles
    """

    def __init__(self, name, city_type, tagline):
        """
        Make a City with no roads yet.

        Args:
            name (str): The city's name
            city_type (str): The city's type
            tagline (str): The city's tagline
        """
        self.__name = name
        self.__city_type = city_type
        self.__tagline = tagline
        self.__connections = {}

    def get_name(self):
        """Return the city's name."""
        return self.__name

    def set_name(self, name):
        """Change the city's name."""
        self.__name = name

    def get_type(self):
        """Return the city's type."""
        return self.__city_type

    def set_type(self, city_type):
        """Change the city's type."""
        self.__city_type = city_type

    def get_tagline(self):
        """Return the city's tagline."""
        return self.__tagline

    def set_tagline(self, tagline):
        """Change the city's tagline."""
        self.__tagline = tagline

    def add_connection(self, dest, miles):
        """
        Add a road from this city to another one.

        Args:
            dest (str): The destination's name
            miles (int): The miles to it
        """
        self.__connections[dest] = miles
  1. Below the class, at the left edge, add a self-test. The game never calls the setters, so this is where you check them: set each one, then read it back with its getter. The guard on the last two lines runs the test only when you run city.py itself, never when the game imports the class:

def build_cities(distances, city_info):
    """
    Make one City object for every city in the data files.

    Args:
        distances (dict): The nested dictionary from load_city_distances()
        city_info (dict): The dictionary from load_city_info()

    Returns:
        dict: cities[name] is that city's City object
    """
    cities = {}
    for name in city_info:
        info = city_info[name]
        cities[name] = City(name, info['type'], info['tagline'])
    for name in distances:
        for dest in distances[name]:
            cities[name].add_connection(dest, distances[name][dest])
    return cities

    def display_destinations(self):
        """
        Show the numbered menu of this city's destinations.

        Returns:
            int: How many destinations the menu shows
        """
        print(f'From {self.__name}, you can travel to:')
        option_num = 1
        for dest in self.__connections:
            miles = self.__connections[dest]
            print(f'  {option_num}. {dest} - {miles} miles')
            option_num = option_num + 1
        return len(self.__connections)

    def get_destination(self, choice):
        """
        Look up the destination for a menu choice.

        Args:
            choice (int): The menu number the player chose, from 1

        Returns:
            tuple: The destination and its distance
        """
        dests = list(self.__connections.keys())
        dest = dests[choice - 1]
        return dest, self.__connections[dest]
