Checkpoint

Choose a Destination
← Back: CP1

The player's first real decision. They pick 1, 2, or 3, and your program sets the destination and its distance. Anything else is an invalid choice, and the player stays in San Antonio.

Why This Matters

An if/elif/else chain runs exactly one branch: the first one whose condition is true, or the else if none are. Every branch sets the same two variables, destination and distance, so the code after the chain works no matter which choice was made.

Step-by-Step Instructions
  1. Leave one empty line after the destination list. Then ask for the choice, as a whole number, with a blank line after it:
    # Choose a destination
    choice = int(input('Choice (1-3): '))
    print()
  1. Right below that, add the chain. Each branch sets destination and distance. The else catches anything that isn't 1, 2, or 3:
    if choice == 1:
        destination = 'Corpus Christi'
        distance = SAT_TO_CORPUS
    elif choice == 2:
        destination = 'Houston'
        distance = SAT_TO_HOUSTON
    elif choice == 3:
        destination = 'Austin'
        distance = SAT_TO_AUSTIN
    else:
        destination = 'San Antonio'
        distance = 0
Indentation is the structure

The lines under each if, elif, and else are indented four more spaces than the line above them: eight spaces in all, because the chain is already inside main(). That indentation is how Python knows which lines belong to which branch. Every one of those lines ends with nothing after it; every if, elif, and else line ends with a colon.

  1. Leave one empty line, then tell the player where they're headed. An invalid choice gets its own message instead:
    # Travel toward the destination
    if distance == 0:
        print('Invalid choice! You stay in San Antonio.')
    else:
        print(f"You're headed to {destination}!")
        print(f'Distance: {distance} miles')
        print()
    print()

The You're headed line uses double quotes on the outside because the text has an apostrophe in it. With single quotes, Python would think the string ends at You.

Did You Make It?
← Back: CP2

The answer to the question the whole lab is about: did your roll get you there? If it did, you made it. If not, you see how far you still have to go.

Why This Matters

This check only makes sense for a real destination, so it goes inside the else from CP2: an if inside another if, called a nested decision. The math is the same direction as Lab 1.1: distance first, then minus miles_rolled. Zero or less means you made it.

"Nested ifs look scary until you read the indentation like an outline. Eight spaces is inside the else. Twelve spaces is inside the if that's inside the else. If a line is at the wrong depth, it's in the wrong place, and Python will do exactly what the indentation says."
Danny Cavanaugh
Lead Developer, Bat City Collective
Step-by-Step Instructions
  1. Find the else block from CP2. After its print() (the one right under the Distance line), add these lines, indented eight spaces so they're inside the else:
        miles_remaining = distance - miles_rolled
        if miles_remaining <= 0:
            print(f'You made it to {destination}!')
        else:
            print(f'Miles remaining: {miles_remaining}')
            print('You will need to roll again next time!')

The print() at four spaces, at the very end of the travel block, stays where it is, below these new lines.

The ending. Where you end up decides what happens: the beach banner for Corpus Christi, a word about Austin, and then the Final Trip Report. It's the same report your game prints all semester; later labs add new sections inside it.

Why This Matters

current_city remembers where the player is. It starts as San Antonio and changes only when you actually arrive. Checking it after the travel block, instead of checking the choice, means the beach banner only prints when you really reached the beach.

Step-by-Step Instructions
  1. Two small additions to code you already have. First, right under the # Choose a destination comment and above the choice line, add:
    current_city = 'San Antonio'
  1. Second, in the made-it branch from CP3, right under the You made it line, add this line, indented twelve spaces:
            current_city = destination
  1. Leave one empty line after the travel block's last print(). Then decide the ending:
    # Where did you end up?
    status = 'Trip Incomplete'
    if current_city == 'Corpus Christi':
        print('=' * 50)
        print('CONGRATULATIONS! YOU REACHED THE BEACH!')
        print('=' * 50)
        print()
        status = 'BEACH WINNER!'
    elif current_city == 'Austin':
        print('Austin is fun, but no beach here!')
        print()
  1. Leave one empty line, then print the Final Trip Report:
    # Final trip report
    print()
    print('=' * 50)
    print('FINAL TRIP REPORT')
    print('=' * 50)
    print(f'Driver: {player_name}')
    print(f'Final City: {current_city}')
    print(f'Status: {status}')
    print()
    print('=' * 50)
    print()

The report starts with its own print(), so two blank lines come before it. That's on purpose: it's the same spacing the report keeps for the rest of the course.
