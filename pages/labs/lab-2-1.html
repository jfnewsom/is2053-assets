Refuse Bad Choices
← Back: CP1

Right now a 5 at the menu means the trip never starts. A while loop fixes that: it keeps asking until the player types 1, 2, or 3.

Why This Matters

A while loop repeats its block as long as its condition is true. Here the condition is "the choice is out of range," so the block runs only when the answer is bad, and the loop stops the moment the answer is good. This is called an input validation loop. Every choice that gets past it is 1, 2, or 3, so the chain's last branch can be a plain else, and the invalid-choice message has nothing left to do.

"Remember the hole I told you about in Lab 1.3? Here's the first patch. Try 5, try 0, try 9: the menu just asks again. The roll prompt is still wide open, but in Lab 2.2 Python takes the dice away from you, and that hole closes too."
Terrence "T-Bone" Booker

The Travel Loop
← Back: CP2

The heart of Module 2. Instead of one roll deciding everything, you roll turn after turn until you arrive. Every trip makes it now; the only question is how many turns it takes.

Why This Matters

The loop keeps going while miles_remaining is more than zero. Each turn subtracts that turn's miles, so the condition eventually turns false and the loop stops. leg_turns is a counter: it starts at 0 and goes up by 1 at the start of each turn. The roll prompt from Module 1 moves inside the loop; in Lab 2.2, Python rolls for you, and that's the line that changes.

"Read a while loop from the bottom of the body back to the top. What changes each time through? miles_remaining. Does that change move it toward the condition being false? Every roll is at least 1, so yes. If you can answer those two questions, your loop ends."
Danny Cavanaugh
Lead Developer, Bat City Collective
Step-by-Step Instructions
  1. After the print() under the Distance line, leave one empty line in your code and add the travel banner:
    # Travel turn by turn until you arrive
    print('=' * 50)
    print(f'TRAVELING TO {destination.upper()}!')
    print('=' * 50)
    print()

.upper() gives you an all-capitals copy of the text, so Houston prints as HOUSTON. It's your first string method. Chapter 8 covers the rest; for now, this banner is the only place you use one.

  1. Leave one empty line, then add the loop. current_city = destination goes after the loop, at four spaces: once the loop ends, you've arrived.
    miles_remaining = distance
    leg_turns = 0
    while miles_remaining > 0:
        leg_turns = leg_turns + 1
        print(f'--- Turn {leg_turns} ---')
        print(f'Miles remaining: {miles_remaining}')
        roll = int(input('Enter your roll (1-20): '))
        miles_this_turn = roll * MILES_MULTIPLIER
        print(f'You rolled a {roll}!')
        print(f'You travel {miles_this_turn} miles...')
        miles_remaining = miles_remaining - miles_this_turn
        if miles_remaining <= 0:
            print()
            print(f'You made it to {destination}!')
        else:
            print(f'Miles remaining: {miles_remaining}')
        print()
    current_city = destination
  1. Check two details. The roll prompt has no print() after it inside the loop, on purpose: in Lab 2.2 the prompt goes away, and nothing else has to change. And Miles remaining prints twice each turn: once before the roll, and again after it if you haven't arrived.

Keep Going to Galveston
← Back: CP3

Galveston is back. Make it to Houston, and the game asks whether you want to keep going, the same question as Lab 1.3. Say yes, and the travel loop runs again for the last 50 miles.

Why This Matters

A loop inside another loop is a nested loop. The loop you wrote in CP3 drives one leg, turn by turn. The new outer loop runs once per leg, and after each leg it decides whether there's another one. That decision is a Boolean variable, like Lab 1.3's reached_beach: playing starts each pass as False, and only a yes in Houston sets it back to True.

"The inner loop drives one leg. The outer loop decides whether there's another leg. Keep those two jobs straight and a nested loop is just two loops you already understand, one inside the other. When I'm not sure which loop a line belongs to, I look at its indentation before I look at anything else."
Danny Cavanaugh
Lead Developer, Bat City Collective
Step-by-Step Instructions
  1. Right above the # Travel turn by turn until you arrive comment, add these three lines, at four spaces:
    # Travel one leg at a time

Why This Matters

An accumulator is a variable that starts at 0 and has something added to it again and again. total_miles adds each turn's miles inside the inner loop. total_turns adds each leg's turns, once per pass of the outer loop. Both start before either loop, so a trip to Galveston counts both legs: leg_turns starts over for the second leg, and the totals don't.

"You'll see total_miles += miles_this_turn in the textbook. It means exactly the same thing as total_miles = total_miles + miles_this_turn, and either one is fine. I write the long way for a while because it reads like a sentence: the new total is the old total plus this turn."

Junior Developer, Bat City Collective
