Key Concepts

An attribute can hold any kind of value, including a list or a set. Player keeps the route in a list (order matters, repeats allowed) and the unique cities in a set (no repeats). A mutator is the only way code outside the class changes a private attribute: the game never touches self.__total_miles; it calls player.travel_to(...), and the method updates five attributes together. The rules for changing the trip live in one place, the class.

What You're Building

One accessor for each attribute, so the game can read the trip without touching a private attribute.

Why This Matters

The trip report, the save file, and the session totals all read the trip. In lab-5-2.py, every one of those reads is an accessor call, like player.get_total_miles(). Twelve accessors in a row is repetitive on purpose: it is the same pattern as City's, and by the fifth one you won't need to look.

A Trip Changes the Player
What You're Building

Three mutators, the methods that change the trip: travel_to, record_hazard, and record_trivia. With them in place, the provided game runs a whole new game from start to finish.

Why This Matters

In Lab 5.1, arriving in a city took five lines scattered through the travel loop: miles, turns, the current city, the route list, and the unique-city set. Miss one and the trip report is wrong. Now the game makes one call, and the method keeps all five in step. Nothing outside the class can update four of them and forget the fifth.

Step-by-Step Instructions
  1. Below the accessors, write travel_to(self, city, miles, turns) with a docstring. It records an arrival: set self.__current_city to city, add miles to self.__total_miles and turns to self.__total_turns, append city to self.__visited_cities, and .add() it to self.__unique_cities.
  2. Write record_hazard(self, name, escaped) with a docstring. Add 1 to self.__total_hazards. Then if escaped:, add 1 to self.__total_escaped. Append name to self.__hazards_list and .add() it to self.__unique_hazards.

One course rule on top of that: to show a number to a set number of decimal places, format it in an f-string, like f'{rate:.1f}', instead of using round(). Here's why: round() changes the number itself, while an f-string changes only what's shown, so the full value is still there for the math that comes later. Picture plotting a course from El Paso to San Antonio: about 500 miles on a steady heading of 108.77 degrees. Round the heading to 109 and you're off by less than a quarter of a degree, which sounds like nothing. Fly it anyway and you miss San Antonio by about 2 miles. Round on every leg of a longer trip and the misses can stack up. Keep the full number for the math, and display only what you print.
