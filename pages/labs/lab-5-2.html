class Player:
    """
    One player's trip in the road trip game.

    Private attributes:
        __name (str): The player's name
        __current_city (str): Where the player is now
        __total_miles (int): Miles traveled this game
        __total_turns (int): Turns taken this game
        __total_hazards (int): Hazards faced this game
        __total_escaped (int): Hazards escaped this game
        __visited_cities (list): Every stop, in order
        __hazards_list (list): Every hazard faced, in order

        __unique_hazards (set): Each hazard faced, once
        __trivia_asked (int): Trivia questions asked this game
        __trivia_correct (int): Trivia questions answered right
    """

    def __init__(self, name):
        """
        Start a new trip in San Antonio.

        Args:
            name (str): The player's name
        """
        self.__name = name
        self.__current_city = 'San Antonio'
        self.__total_miles = 0
        self.__total_turns = 0
        self.__total_hazards = 0
        self.__total_escaped = 0
        self.__visited_cities = ['San Antonio']

        self.__unique_hazards = set(self.__hazards_list)
        self.__trivia_asked = 0
        self.__trivia_correct = 0

    def __str__(self):
        """Return the player as text, like 'Tester in Houston (200 miles)'."""
        return (f'{self.__name} in {self.__current_city} '

Twelve Getters and Setters
← Back: CP1

A getter and a setter for every attribute, side by side: twelve pairs. The getter returns one attribute; the setter changes it.

Why This Matters

The trip report, the save file, and the session totals all read the trip: in lab-5-2.py, every one of those reads is a getter call, like player.get_total_miles(). The game doesn't call the setters yet, but they're how code outside the class changes one value at a time, and they're what the next feature will use. Twenty-four short methods in a row is repetitive on purpose: it's the same pattern as City's, and by the fifth pair you won't need to look.

Step-by-Step Instructions
  1. Below the getters and setters, add the three methods:
    def travel_to(self, city, miles, turns):
        """
        Record arriving in a city.

        Args:
            city (str): The city the player arrived in
            miles (int): Miles traveled to get there
            turns (int): Turns it took to get there
        """
        self.__current_city = city
        self.__total_miles = self.__total_miles + miles
        self.__total_turns = self.__total_turns + turns
        self.__visited_cities.append(city)
        self.__unique_cities.add(city)

    def record_hazard(self, name, escaped):
        """
        Record one hazard.

        Args:
            name (str): The hazard's name
            escaped (bool): True if the player escaped it
        """
        self.__total_hazards = self.__total_hazards + 1
        if escaped:
            self.__total_escaped = self.__total_escaped + 1
        self.__hazards_list.append(name)
        self.__unique_hazards.add(name)

    def record_trivia(self, correct):
        """
        Record one trivia question.

        Args:
            correct (bool): True if the player answered right
        """
        self.__trivia_asked = self.__trivia_asked + 1
        if correct:
            self.__trivia_correct = self.__trivia_correct + 1

    def resume(self, current_city, total_miles, total_turns,
